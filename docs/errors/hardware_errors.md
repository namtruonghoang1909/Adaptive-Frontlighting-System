# Bench Hardware And Wiring Errors

No confirmed matrix, servo, or bench-power failure has been recorded yet. The
hardware design is still a candidate and should be checked against the exact
board, module, and transceiver before powering a new connection. The current
pin and wiring assumptions are tracked in the
[wiring draft](../hardware/wiring-draft.md) and the
[hardware wiring view](../../tools/system_visualization/hardware-wiring/index.html).

When a hardware issue occurs, record the exact module markings, power source,
measured voltages, wiring, and observable symptom. For CAN transceiver and bus
symptoms, see [CAN errors](can_errors.md); for probe power, permissions, and
SWD signals, see [ST-Link errors](stlink_errors.md).
