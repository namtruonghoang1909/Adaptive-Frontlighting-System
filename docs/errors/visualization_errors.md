# System Visualization Errors

No confirmed System Visualization runtime error is recorded here yet. For a
new issue, capture the page URL/path, browser console output, selected tab, and
whether the local visualization server is running.

After changing a visualization page or model, run its focused checks:

```bash
bash tests/scripts/test_visualization.sh
```

The Code graph also has an inventory freshness check and graph validator; see
the [visualization guide](../../tools/system_visualization/README.md).
