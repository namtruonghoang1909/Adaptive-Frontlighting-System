# CAN

Future native CAN conversion, periodic scheduling, raw Linux SocketCAN TX/RX, receive filtering, application counters/checks, and ECU-status decoding.

This module is the production host owner of project CAN traffic. It receives simulator-independent state from the bridge state layer and never calls Python at runtime. A future DBC-derived codec will define mechanical signal packing; STM32 retains AFS/ADB control.
